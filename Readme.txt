# استودیو محصول — راهنمای فایل‌ها

یک PWA کاملاً موبایل‌محور برای حذف پس‌زمینه و آماده‌سازی عکس محصولات فروشگاه، تماماً با HTML/CSS/JS خام (بدون فریم‌ورک) و بدون نیاز به سرور اختصاصی.

## فایل‌ها چه کاری انجام می‌دهند

| فایل | کار آن |
|---|---|
| `index.html` | ساختار کل برنامه: صفحهٔ خانه («انتخاب عکس») و صفحهٔ ادیت (کانواس، نوار ابزار، شیت‌های تنظیمات، شیت ذخیره‌سازی). |
| `styles.css` | تمام ظاهر برنامه — تم تیرهٔ استودیویی، دکمهٔ شاتر، نوار ابزار اسکرول‌شونده، اسلایدرها و شیت‌های کشویی. Responsive و مخصوص موبایل. |
| `app.js` | مغز برنامه: بارگذاری عکس، پایپ‌لاین رندر (تنظیمات → بلور/شارپ → پس‌زمینه/سایه → ترکیب نهایی)، همهٔ ابزارهای ادیت (برش، چرخش، تنظیمات نور و رنگ، فیلترها، قلم‌مو، رنگ پس‌زمینه، سایهٔ محصول، فاصله از لبه)، تاریخچهٔ واگرد/ازنو، و ذخیره‌سازی خروجی. |
| `bg-removal.js` | موتور حذف پس‌زمینه. کاملاً داخل مرورگر کار می‌کند (بدون هوش مصنوعی خارجی یا API). از تکنیک «رشد ناحیه از لبه‌های عکس» استفاده می‌کند، لبه‌ها را نرم می‌کند و رنگ لبهٔ محصول را از رنگ پس‌زمینه «پاک‌سازی» می‌کند تا هالهٔ سفید/خاکستری ایجاد نشود. **این فایل عمداً مستقل و ساده نگه داشته شده** تا در آینده بتوانی داخل آن یک مدل هوش مصنوعی یا یک API حرفه‌ای حذف پس‌زمینه را جایگزین کنی، بدون اینکه لازم باشد بقیهٔ برنامه را تغییر بدهی (توضیح کامل‌تر پایین همین فایل). |
| `manifest.json` | تنظیمات PWA (نام، آیکون، رنگ‌ها) تا بشود برنامه را از سافاری آیفون به صفحهٔ اصلی اضافه کرد. |
| `sw.js` | سرویس‌ورکر — فایل‌های برنامه را کش می‌کند تا برنامه سریع باز شود و تا حد امکان آفلاین هم کار کند. |
| `icon-192.png`, `icon-512.png` | آیکون برنامه برای صفحهٔ اصلی و اسپلش‌اسکرین. |

## چطور آپلود/اجرا کنم؟

دقیقاً مثل shop.html و admin.html: همهٔ این فایل‌ها را در ریشهٔ یک ریپازیتوری روی GitHub (می‌تواند همان ریپازیتوری فعلی یا یک ریپازیتوری جدید باشد) آپلود کن و GitHub Pages را برایش فعال کن. بعد از باز کردن لینک در سافاری آیفون، از دکمهٔ Share گزینهٔ «Add to Home Screen» را بزن تا مثل یک اپلیکیشن جدا نصب شود.

## دربارهٔ کیفیت حذف پس‌زمینه

الگوریتم فعلی برای عکس‌هایی که با یک پس‌زمینهٔ نسبتاً یکدست (میز، دیوار، پارچه) گرفته شده‌اند خیلی خوب کار می‌کند و کاملاً واقعی و کاربردی است — نه یک دکمهٔ نمایشی. برای عکس‌های شلوغ یا پس‌زمینه‌های خیلی نامنظم ممکن است نیاز به اصلاح دستی با ابزار «قلم‌مو» (حذف/بازگردانی) داشته باشی، که در برنامه گنجانده شده.

اگر بعداً خواستی کیفیت را با یک مدل هوش مصنوعی (مثلاً یک API ابری یا یک مدل درون‌مرورگری) بالاتر ببری، فقط کافی است:
1. در `bg-removal.js` یک تابع async جدید بنویسی که همان ورودی (یک canvas) را بگیرد و همان خروجی (`{ maskCanvas }`، یعنی یک canvas با کانال آلفای درست) را برگرداند.
2. در `app.js`، در دو جای مشخص (`runRemoveBackground` و `runPrepareProduct`)، فراخوانی `BgRemoval.removeBackgroundSmart(...)` را با تابع جدیدت عوض کنی.

هیچ بخش دیگری از برنامه (قلم‌مو، رنگ پس‌زمینه، سایه، برش، ذخیره‌سازی) نیازی به تغییر ندارد.

## نکات فنی

- برای سرعت روی موبایل، ادیت روی نسخه‌ای از عکس با حداکثر ابعاد ۱۴۰۰ پیکسل انجام می‌شود (`MAX_DIM` در `app.js`). برای اکثر عکس‌های فروشگاهی این کاملاً کافی است؛ اگر خواستی خروجی با ابعاد بزرگ‌تر داشته باشی، این مقدار را در `app.js` افزایش بده (روی گوشی‌های قدیمی‌تر ممکن است کندتر شود).
- تمام پردازش‌ها (حذف پس‌زمینه، فیلترها، تنظیمات) کاملاً روی خود گوشی و در مرورگر انجام می‌شود؛ هیچ عکسی به هیچ سروری فرستاده نمی‌شود.
- دکمهٔ «ذخیره عکس» هم دانلود مستقیم را امتحان می‌کند و هم یک پیش‌نمایش نشان می‌دهد که می‌توانی با لمس‌ولمس‌نگه‌داشتن آن، طبق روال معمول سافاری، در گالری ذخیره کنی.
